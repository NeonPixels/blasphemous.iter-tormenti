<details>
  <summary><b>I have already defeated Esdras, will this mod revive him?</b></summary>
  <br/>
  No. If Esdras has already been defeated in the save, this mod will not change anything.
</details>
<details>
  <summary><b>The Amanecidas are too tough for a non-ascended run</b></summary>
  <br/>
  Since the Amanecidas are only meant to appear in an ascended run, they have no scaling data to balance them for regular runs.
</details>
<details>
  <summary><b>Is this mod compatible with other mods?</b></summary>
  <br/>
  Depends. The Penances are added using the Penitence framework, and should be compatible with other modded Penances using the framework.<br>
  Any mod that alters the Esdras encounter will possibly be incompatible.<br>
</details>
